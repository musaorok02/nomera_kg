# НомераКР — каталог фото автомобилей по госномерам Кыргызстана

Django 5.2 + PostgreSQL + Gunicorn + Nginx. Рассчитан на CentOS Stream 9 / Rocky / AlmaLinux 9.

## Возможности

- Регистрация и вход, смена пароля
- Загрузка фото: водяной знак, удаление EXIF/GPS, автоповорот, миниатюры, лимит в сутки
- Нормализация номеров: `01 KG 123 ABC`, `01kg123abc`, `01 123 АВС` (кириллица) — один и тот же номер
- Поиск по номеру или его части, фильтры по региону и марке
- Страница номера со всеми его фото
- Каталог: марки, модели, регионы КР (01–11), цепочка «марка → модель» в форме загрузки
- Лайки (AJAX), комментарии, лента «Новые» и «Лучшие» (сутки/неделя/месяц/всё время)
- Профили авторов, статистика (регионы, марки, самые снимаемые номера, авторы)
- Модерация: очередь новых фото, одобрить/отклонить с причиной; автопубликация для staff
- Жалобы на фото, отдельная причина «я владелец авто» для запросов на удаление
- JSON API: `/api/search/?q=`, `/api/plate/<номер>/`, `/api/models/?brand=<id>`
- `sitemap.xml`, `robots.txt`, OpenGraph-теги, админка Django

## Быстрый запуск локально

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
export DEBUG=1                      # без DB_NAME используется SQLite
python manage.py migrate
python manage.py seed_data          # регионы и марки/модели
python manage.py createsuperuser
python manage.py runserver
```

Тесты: `DEBUG=1 python manage.py test`

## Установка на CentOS

1. Скопируйте папку проекта на сервер (например, в `/root/nomera_kg`).
2. От root:
   ```bash
   cd /root/nomera_kg
   DOMAIN=example.kg SITE_NAME="НомераКР" bash deploy/install_centos.sh
   ```
   Скрипт ставит пакеты, создаёт БД и пользователя, `.env` со случайными секретами,
   виртуальное окружение, применяет миграции, настраивает systemd, Nginx, firewalld, SELinux.
3. Создайте администратора:
   ```bash
   sudo -u nomera bash -c "cd /opt/nomera && venv/bin/python manage.py createsuperuser"
   ```
4. Включите HTTPS: `certbot --nginx -d example.kg -d www.example.kg`, затем в `/opt/nomera/.env`
   поставьте `HTTPS=1` и выполните `systemctl restart nomera`.

Обновление кода: заново скопировать проект и запустить тот же скрипт (`.env`, БД и фото сохраняются).

Если у вас CentOS 7: он снят с поддержки, а Python 3.11 и PostgreSQL 13+ там нет. Лучше взять
Rocky/AlmaLinux 9 или CentOS Stream 9.

## Структура

```
config/      настройки (.env), urls, wsgi
accounts/    регистрация / вход
catalog/     модели, формы, views, обработка изображений, тесты, seed_data

```

## Важно

- **Коды регионов** (01 Бишкек, 02 Ош, 03 Баткен … 09 Иссык-Куль, 10 легализованные, 11 временный ввоз)
  взяты из публикаций ГРС/«Унаа». Проверьте и при необходимости поправьте в админке (`/admin/` → Регионы).
- **Персональные данные.** Сайт не должен показывать данные владельцев. Оставлены правила, страница
  «Конфиденциальность», форма жалобы с причиной «я владелец авто», ручная модерация новых фото.
  Перед запуском проконсультируйтесь с юристом по закону КР «Об информации персонального характера»
  и подготовьте нормальный текст пользовательского соглашения.
- Ограничение частоты жалоб/комментариев использует файловый кэш (работает между воркерами Gunicorn).
  Для большого трафика подключите Redis и CAPTCHA на регистрации.
- Сброс пароля по email не включён (нужен SMTP): добавьте `django.contrib.auth.urls` password_reset
  и настройте `EMAIL_*` в `.env`.
- Фото хранятся на диске сервера (`/var/www/nomera/media`): делайте бэкапы вместе с `pg_dump`.
